jobs

jobs that get interrupted (crash, power loss) are automatically marked failed rather than left stuck "running" — already-committed work is never lost or corrupted, just whatever was mid-batch when it stopped. Sync and clustering jobs are safe to just re-run (they skip what's already done); an "untagged stories only" extraction re-run picks up where it left off too.

how auto-tagging works

Nothing here runs on its own — every step below is a job you start by hand, and each one only does its own stage of the pipeline:

  1. Write or pick a prompt (prompts page) — the instructions that tell the model what to look for. Different prompts can target different facets (e.g. one for theme/content, another for setting/style) and are run as separate extraction passes.
  2. Start an extraction pass — runs your chosen model over stories one at a time and asks it to propose tags per the prompt. Results land in a holding area (tag_candidates) only — nothing shows up on browse, the tag cloud, or story pages yet. "untagged stories only" scope skips any story that already has at least one tag, so it's the right choice for topping up a library after adding new stories or running a different prompt, without re-tagging everything.
  3. Start a clustering pass — the step that actually makes tags visible. It embeds every still-pending candidate and merges near-duplicate phrasings (e.g. "road trip" / "cross-country drive") into one canonical tag, then links that tag to each story. This is what populates browse, the tag cloud, and story pages — run it any time after an extraction pass to fold in whatever's accumulated so far, and again later for whatever's accumulated since; it only processes candidates no prior clustering run has already handled, so re-running is always safe and never redoes work.
  4. Results (results) — model-applied tags are live immediately after clustering, not held back pending approval; results is a worklist of stories that still have unreviewed model tags, so a human can spot-check them, marking each human-reviewed or removing it, at their own pace without blocking the tags from being usable meanwhile.
